# Reflections

## What was the breakthrough that moved the work forward?

The pivot from focusing on monte-carlo to pseudo-random number generators, as described in Moment 1 of my PROCESS.md. It allowed me to firmly pick a target audience of high-school-level mathematical literacy and write an article based on that. It is slighlty technical, because it needs to be, but it allows me to actually explain the topic beyond a superficial level because the technical side is simple enough. So this decision solidified the topic and tone, through with the audience and interactive elements naturally followed.

## What did this work change about who I want to be as a software developer?

This assignment actually did cause some reflection and change in some of my aspirations. More specifically, I have, for some time, wanted to create educational explainer vidoes, and I have taught and run courses in the past. More broadly, I tend to master a topic better through teaching than as a student. Consequently, this project makes me want to create a personal website where I explain technical topics

I would create it with minimal AI assistance beyond tooling and debugging, as the act of creating and maintaining a website and the interactive elements has value.

Of course, from a computer science career perspecitve, it'd be an excellent portfolio work.
